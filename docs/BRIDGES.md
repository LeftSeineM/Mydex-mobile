# 连接桥与一键恢复

适用 Windows 0.4.23 · 2026-11-03

[下载](https://app.leftseinem.dpdns.org/) · [安装与配对](GETTING-STARTED.md)

连接桥让 Mydex 连接电脑上原工具已有的会话，沿用原账号和模型配置，不新建独立 CLI 替代任务。工具页显示实际安装方式，点击“桥接说明”可查看修改和恢复范围。安装文件成功与原会话真正连通分开检查。

## 两种安装方式

| 方式 | 做了什么 | 一键恢复做什么 |
|---|---|---|
| 原地兼容桥 | 备份并修改原安装中的程序文件 | 校验匹配备份后还原程序文件 |
| Claude 商店版兼容副本 | 复制同版本程序，在副本加入桥；原 WindowsApps 安装不改 | 删除 Mydex 创建的副本及其程序备份 |

副本不是与原版完全相同的文件，修改可能影响厂商签名。它沿用原有数据目录，不搬走原账号或聊天记录；原版和副本不能同时使用该目录。副本位置在安装窗口可以选择，默认无需修改。回退不会删除所选父目录或其中其他文件，也不会回滚聊天内容。

## 如何恢复

1. 先保存工作并退出对应工具；副本方式只需退出 Claude 兼容副本。
2. 打开 Mydex → 工具接入，选择对应工具。点击“还原原版”，或 Claude 的“回退并删除副本”。
3. 查看确认窗口中的恢复范围和目录，确认后等待结果。然后可从原有快捷方式启动原工具。

无需终端命令，也无需重新填写 API Key 或模型。Mydex 不会强行终止任务。旧版 0.4.22 创建的兼容副本也支持校验后回退。若文件被锁定可退出工具后重试；若发现目录链接、未知文件、原工具被更新或归属不符，自动恢复会停止，避免误删或覆盖其他内容。

## 当前能力范围

Claude 的 Code 原会话接口已经在小主机检测连通。Cowork 的运行环境和手机接入尚未完成兼容验证，副本可能出现修复或重装提示。旧记录文件保留，不等于所有类型均已在手机显示或可继续执行；请以工具页实际能力为准。不要通过删除原账号数据来处理此类提示。

本次安装、恢复、旧副本清理、失败重试和目录保护经过隔离测试；没有在用户正在使用的 Claude 上实际执行删除或还原。更新 Mydex 不会自动移除现有连接桥。
