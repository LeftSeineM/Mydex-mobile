# Mydex 完整功能图解

版本 Android 0.2.9 / Windows 0.4.6 · 2026-10-30

[首页](../README.md) · [安装与配对](GETTING-STARTED.md) · [截图全集](SCREENSHOTS.md)

## 1. 电脑连接概览

连接概览显示本机连接服务状态。先配置地址，再启动服务；手机通过自己的连接入口访问电脑。关闭窗口通常收起到托盘，选择退出才会停止本应用管理的服务。其他独立启动的服务不会被冒充为本应用所有。

![电脑概览](images/desktop-overview.png)

## 2. 扫码配对与粘贴备用

电脑生成两分钟有效的一次性码；手机扫描、核对电脑名称，再确认。二维码携带地址、证书指纹和临时邀请，不展示长期访问令牌。刷新废弃旧码，使用后不可重放。相机仅在扫码时使用，图像不上传到第三方。

<table><tr><td><img src="images/desktop-pair-qr.png" width="350" /></td><td><img src="images/add-computer.png" width="300" /></td></tr></table>

不能扫码时仍可复制完整配对信息，在手机粘贴后保存。网络地址可达是两种方式共同的前提。

## 3. 多电脑与工具下拉选择

每台电脑保留独立连接信息，手机下拉选择当前电脑和工具。笔记本下线不会使另一台常开电脑必须下线。切换工具会切换项目、标题和控制区，不沿用上一个工具的模型选项。电脑检测页分别说明进程、会话读取和继续对话能力。

![工具接入](images/desktop-tools.png)

## 4. 项目和原会话

项目区用于定位工作目录，最近对话用于快速回到原会话。选中会话后加载其历史；发送消息交给电脑原工具处理。支持原会话接入的工具会继续同一会话上下文，不把历史复制成另一套 Agent。若某工具没有项目元数据，会显示空项目区，仍可从最近对话进入。

<img src="images/projects.png" width="340" />

## 5. 对话、状态与运行过程

用户消息和 Agent 输出分开显示。任务区分排队、运行中、待审批、完成和失败。通过 WebSocket 接收变化；不同工具提供的生成中内容能力不同，不承诺所有工具都逐 token 返回。长信息可收起，一轮多次脚本执行合并到运行过程，展开再看具体步骤。

<img src="images/conversation.png" width="340" />

阅读旧消息时不会强行把你拖回底部；需要时点击回到最新消息。切换到另一会话会加载对应历史，不混入别的任务输出。

## 6. 截图与审批

工具提供的图片在对话中显示卡片，点击可打开预览并缩放。截图来自当前电脑服务，不上传到公共图床。是否能展示取决于原工具是否暴露相应图片。

对于支持审批接口的 Codex 操作，手机显示待审批卡片、操作说明以及同意或拒绝按钮。支持时会震动提醒。Claude、Kimi、DeepSeek、ZCode、Gemini 的高危权限审批仍需在原电脑处理；手机不会替你自动同意。

## 7. Codex 模型、快速模式、队列与目标

控制区按电脑返回的能力显示模型、思考强度、快速模式、队列和目标控制。选择范围来自电脑接口，不把模型密钥保存在手机。部分旧会话的模型选择会在下一次发言应用。

<img src="images/controls.png" width="340" />

这些选项不是对所有工具的统一承诺。非 Codex 工具的模型与权限仍在原客户端配置。

## 8. 折叠屏与手机布局

窄屏以全屏对话为主；展开后左侧导航、右侧对话。折叠或展开保留当前对话和未发送草稿，布局考虑键盘与屏幕铰链区域。

![折叠屏](images/foldable.png)

## 9. 托盘和登录自启

Windows 设置管理登录后自启、数据目录和联系开发者入口。托盘可以打开窗口、启动服务、停止本应用管理的连接或退出。自启指用户登录后启动，不等于电脑断电后仍能执行任务。

![设置](images/desktop-settings.png)

## 10. 更新、缓存和连接数据

手机设置可检查当前电脑提供的更新，下载安装包后由 Android 系统确认覆盖安装。不会静默替你安装。更换电脑端模型供应商通常不需要重装 APK。

“清除本地会话缓存”保留电脑原会话；移除连接会清除相应本地配置。访问令牌使用安全存储。无 Google 登录、无第三方 AI SDK、无广告统计，模型运行和任务执行留在电脑。

## 12. 反馈和边界

软件不会自动提供网络穿透，不会把远程电脑变成投屏，不在手机运行大模型。安装 APK 也不会自动修改第三方电脑应用。新用户需要先确认对应工具接入条件。

请通过 [GitHub Issues](https://github.com/LeftSeineM/Mydex-mobile/issues) 或 [348897402@qq.com](mailto:348897402@qq.com) 联系开发者，附版本号与复现步骤，遮盖凭据和个人对话。

## 下一步建议与输入框（Android 0.2.7）

<img src="images/prediction.png" width="320" />

1. 在连接设置开启「下一步建议」并保存，默认关闭。
2. 打开一条已经完成、可续聊的会话，清空输入框后点击「建议下一步」。
3. 灰色文字是待采用建议，点击「采用」或外接键盘按 Tab，才会填入草稿；仍需点发送。
4. 直接输入自己的文字会取消建议；切换会话后旧请求的结果不会进入新会话。

这是 Mydex 自己的可选建议功能，尚未接入原 Codex 的账号预测服务，也不代表完整 1:1 映射。请求由电脑上单独配置的模型处理，最多使用最近 6 条文字、每条最多 2000 字符；可能产生该模型的 API 用量。不会自动调用，不执行工具，不修改原会话。图片、脚本执行块不作为建议上下文。手机不保存模型密钥。

需要电脑连接器 0.4.5，并由电脑管理员配置预测模型。未配置时会提示，正常对话不受影响。当前没有图形化模型配置向导；电脑配置方法见下面。

### 电脑端预测配置

在电脑私有目录放置 `prediction.json`，字段为 `baseUrl`（HTTPS、OpenAI Chat Completions 兼容地址，通常以 `/v1` 结尾）、`key`、`model`。在该电脑网关私有 `config.json` 增加 `predictionFile`，值为此文件绝对路径，然后退出并重启 Mydex。不要将这两个文件上传到公开仓库。第三方模型必须支持 `/chat/completions`；失败时手机显示提示，可继续手动输入。

## 长会话与完整日志（0.2.8）

打开对话先取最近 60 条，点击加载历史继续查看。超长文字、脚本日志只在会话中显示预览，点击「分段查看完整内容」或「分段查看完整日志」，用上一段、下一段阅读，每段最多 16000 字符。复制按钮仅复制当前段。内容在电脑端变化时会提示重新打开。手机不会一次拉取整个长日志。

## 字体调节（0.2.9）

连接设置中调整字体至 60%～200%，每档 5%，看预览后保存即可。点「恢复 100%」可回到默认大小，同样需要保存。显示大小会与系统字体缩放叠加。
