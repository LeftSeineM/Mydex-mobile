# Mydex Linux · 0.1.0-preview.3

适用于 Ubuntu 24.04 / Debian 12+ 的 x86-64 桌面连接器。已经在 Ubuntu 24.04 云端虚拟图形桌面验证。手机仍使用现有 Android APK 或网页版。

## 安装

下载 `.deb` 后用系统软件安装器打开，或在下载目录运行：

```sh
sudo apt install ./Mydex-0.1.0-preview.3-linux-amd64.deb
mydex
```

应用菜单中也可以打开 **Mydex**。安装包自带 Node 运行时，系统包管理器负责补齐 Python/Tk、AppIndicator 和 polkit 依赖。无需 Google Play。

## 连接自己的电脑

1. 在“连接概览”确认电脑名称和本机 HTTPS 地址，点击“首次配置并连接”。
2. 保持电脑联网，在“配对手机”生成网页配对二维码。
3. 手机打开 Mydex 网页并登录，在网页内扫码，核对确认码后绑定。使用同一账号可找回已绑定电脑；每台电脑分别配对。
4. Android 客户端也可使用“复制全部连接信息”，在添加电脑页面粘贴。

## Codex 原会话

先安装官方 Linux 桌面应用并配置自己的账号或 API。连接器会自动发现官方包附带的 Codex 引擎；没有引擎时工具不可用。

在电脑 Codex 中打开要继续的对话，再在手机选择这台电脑和这条会话。手机发送、电脑回聊仍在同一条原会话中，沿用桌面的模型和账号。Linux 版目前需要电脑先载入目标对话，新建会话由电脑发起；不会把失败的桌面续聊改成独立命令行任务。

## DSH（DeepSeek Harness）原会话

DSH 官方 Linux 使用 Web UI。按官方教程启动 `dsh web`，保持这个持久进程运行，账号与模型配置在 DSH 自己的界面中完成。

在 Mydex 的“Coding 工具”页面粘贴官方启动信息中的完整 `http://127.0.0.1:端口/?token=…` 地址，点“连接本机 DSH 原会话”。它只接受本机回环地址，验证原会话接口后私下保存本机连接凭据；模型 API 密钥不交给手机。

电脑浏览器中原有 DSH 会话会出现在手机的工具列表中，可双向续聊。不要把 DSH 启动地址公开分享；凭据失效时复制最新启动地址重新连接。此功能连接现有 DSH Web 进程，不为每条手机指令另起 CLI 任务。

## 托盘与开机自启

设置中可以开启“登录 Linux 桌面后自动启动”。有 AppIndicator 托盘服务时，关闭窗口会收起；托盘菜单可打开窗口、切到配对页或完全退出。没有托盘服务时会提示，避免隐藏后找不到应用。完全退出会停止本程序启动的连接。

## 软件更新

设置页提供“检查更新 → 下载更新 → 授权安装”。软件也会定期检查。更新清单验证 Ed25519 签名，下载包验证大小和 SHA-256，普通用户安装时需确认 Linux 系统授权。安装完成后重新打开 Mydex，保留原配置和配对。

## 验证范围与配置位置

Ubuntu 24.04、x86-64：真实 AppIndicator 注册及菜单、二维码实际 PNG 解码、一次性配对和账号隔离、TLS 中继访问网关、Codex 桌面与 DSH Web 的三轮同一会话双向续聊已通过。测试使用虚拟图形桌面；未宣称物理手机摄像头或所有 Linux 发行版测试通过。系统安装器在 root 测试容器中实装通过，普通用户授权取消路径有自动化测试。

配置默认保存在 `~/.local/share/mydex`，DSH 本机凭据在 `~/.mydex/desktop-bridges/deepseek.json`，目录/文件仅当前用户可访问。遵循 `XDG_DATA_HOME`；卸载软件默认不删除配对历史。

模型凭据、任务执行都留在自己的电脑。发布包不含维护者账号、API 密钥或对话记录。

构建：`sh tools/build-linux.sh`（在对应架构的 Linux 上执行）。本次公开包仅提供 amd64。
