# 更新与版本

当前版本：Android 0.2.16（19） / Windows 0.4.17 / Mac 测试版 0.5.1-preview.5。

[下载最新版本](https://github.com/LeftSeineM/Mydex-mobile/releases/latest) · [首页](../README.md)

## Windows 0.4.17

工具接入新增 Claude Desktop 兼容桥的一键安装和还原。安装时检查程序结构、备份原文件；请先退出 Claude。安装和还原已用 Windows Claude Desktop 2.42304.0 的原文件副本验证，其他版本与未来更新不保证兼容。

## Android 0.2.16

设置新增“管理已添加电脑”，支持删除离线设备、配对去重；新版扫码无需 Tailscale 账号，优先当前地址与局域网直连，无法直连时使用加密备用通道。需配套电脑版 0.4.16 后重新扫码一次。普通代理不参与连接；VPN 全局/TUN 模式兼容性尚未完成真机验证。

## Android 0.2.13

修复安卓不能删除电脑的问题：支持删除离线电脑，清除对应连接凭据和当前缓存，保留电脑原会话及其他设备；同一电脑换地址后重新配对自动合并。现有连接方式保持不变，新的轻量自动联网仍在独立开发。

## Android 0.2.12

新增 Codex 权限状态显示与手动切换；审批、选择题和填空题固定在输入框上方。权限切换用于后续消息，不自动回答已有请求。 [权限与问题交互说明](PERMISSIONS.md)。

## 手机更新

设置 → 检查更新 → 下载 → 系统确认安装。APK 使用原签名，可覆盖旧版，无需先卸载。若提示允许安装未知来源，请仅对正在使用的更新入口开启所需安装权限。

更新清单与安装包来自当前连接电脑的更新入口；普通安装者不会自动接入开发者的小主机。电脑端未配置更新源时，可以从公开 Releases 手动下载安装包。

## 电脑更新

退出 Mydex 连接器后运行新版 Setup，保持原安装和数据目录。便携用户先保留 data，再覆盖程序文件。不要清除已有配对配置，也不必重装原 Coding 工具。更新兼容桥需匹配第三方工具版本。

## Android 0.2.6

修复手机将打开已有会话误判为新建会话，导致非 Codex 工具输入框被禁用的问题。原会话需仍由电脑工具提供可写接口；历史文件记录仍只读。设置新增字体缩放 85%–140%，保存后应用并叠加系统字体。

灰色预测输入（Tab 接受建议）仍在接入调查中，本版未包含。电脑端继续使用 0.4.4。

## 0.2.5 / 0.4.4

新增本地相机扫码配对、HTTPS 一次性邀请、两分钟过期与刷新失效；保留粘贴配对。电脑增加二维码窗口与倒计时。公开资料与源码仓库分离，补充完整图文教程和截图。

扫码解码使用随 APK 提供的 ZXing，无需 Google Play 或在线扫码服务。新增相机权限仅用于扫码；拒绝后可以粘贴配对。

## Android 0.2.8 / Windows 0.4.6

修复手机偶发「响应过大」：任务列表仅传摘要，HTTP 和 WebSocket 的会话详情每次最多 60 条；单条超长文本、脚本日志显示预览，点击后分段读取完整内容。原始会话仍保留在电脑。

- 发送回复不再附带整个会话；翻阅历史时保留会话隔离。
- 手机合并连续的实时消息窗口，超大日志单独分页查看、复制本段。
- 如其他接口仍超限，错误提示显示接口位置，便于定位。

验证：超过 24 MiB 的多语言历史、单条 25 MiB 消息、HTTP/WS、翻页新增消息、内容版本变化和鉴权测试通过。26 项 Flutter 测试与 29 项网关测试通过，1 项 Unix 测试在 Windows 跳过。实体手机的安装与运行仍需用户确认。
