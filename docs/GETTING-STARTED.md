# 安装与扫码配对

适用 Android 0.2.14 / Windows 0.4.14 · 2026-11-01

[首页](../README.md) · [下载](https://github.com/LeftSeineM/Mydex-mobile/releases/latest) · [功能图解](FEATURES.md)

## 1. 准备电脑和手机

Windows x64 电脑、Android 6.0 或以上手机，以及手机能访问的电脑 HTTPS 地址。无需 Google Play。原 Coding 工具需要在电脑上安装、配置并正常运行。手机不需要保存模型 API Key。

## 2. 安装电脑连接器

下载 Windows Setup 安装包，默认安装到 D:\Software\MydexMobileApp；没有 D 盘可在安装界面选择其他可写目录。安装包自带运行环境，不创建桌面快捷方式，可从开始菜单打开 Mydex。便携 ZIP 需完整解压后启动。

![连接概览](images/desktop-overview.png)

首次进入“配置本机”，填写电脑名称、手机可访问的 HTTPS 地址，以及程序提示需要的原工具接入信息。保存后启动连接，确认“本机服务已就绪”。已有配置不要随意删除或重新生成。

## 3. 让手机能访问这台电脑

保持电脑开机并运行 Mydex。新版扫码会保存固定设备身份，优先局域网和当前地址直连，无法直连时使用加密备用通道，不需要 Tailscale 账号或额外组网应用。小主机离线时可在同一局域网直连；跨网络不保证可用。旧版连接请更新电脑与手机后重新扫码一次。

<small>使用 VPN 时建议选择规则／分流模式；若无法连接，请关闭全局／TUN 模式后重试。</small>

## 4. 安装手机 APK

下载 Android APK，按系统提示允许浏览器或文件管理器安装该应用。无需卸载旧版；同一签名的新版可覆盖安装。不要先清空旧版连接数据。

## 5. 电脑显示一次性二维码

电脑进入“配对手机”，点击“选择应用版 → 生成配对二维码”。有效时间两分钟，成功兑换后失效；刷新会立即废弃旧码。

![配对入口](images/desktop-pair.png)

<img src="images/desktop-pair-qr.png" width="430" />

图中是 UI 演示码，不可连接真实电脑。

## 6. 手机扫一扫并确认

手机进入“添加电脑”，点击“扫描电脑二维码”，仅在使用时允许相机权限。对准电脑二维码，检查弹出的电脑名称与地址，再点“确认配对”。应用核验二维码中的证书指纹，兑换连接凭据后保存并连接。

<img src="images/add-computer.png" width="340" />

取消扫码不会修改原连接。相机权限未允许、设备无相机、扫码不便时，电脑复制全部配对信息，手机点击“粘贴全部配对信息”，再保存连接。请通过自己的可信通道传递，不要发到公开群聊或 Issues。

## 7. 选择电脑、工具与对话

首页下拉选择电脑，再选择工具。进入项目或最近对话，打开已有会话，在输入框继续发言。不同工具的项目和控制状态隔离；空项目列表不代表没有会话。

<img src="images/projects.png" width="340" />

新增第二台电脑时，直接扫描第二台电脑的码。两台电脑不必相互配对，也不必经过同一个中转入口。

## 8. 检查更新

手机设置 → 检查更新 → 下载 → 按系统提示确认安装。更新入口来自当前连接的电脑；该电脑需提供新版安装包。电脑端从 Releases 下载新版安装包覆盖安装，保留原数据目录。

## 配对失败怎么办

| 情况 | 处理 |
| --- | --- |
| 二维码过期或已用 | 在电脑刷新后重扫，检查手机时间 |
| 无法生成二维码 | 更新电脑连接器到 0.4.4，并启动本机连接服务 |
| 能扫码但连接超时 | 检查手机网络是否能到达该地址、电脑是否休眠、防火墙端口是否可达 |
| 证书验证失败 | 重新从自己的电脑生成二维码，不随意删除验证信息 |
| 兑换后网络中断 | 查看是否已保存连接；若未保存，在电脑刷新二维码重配 |
| 相机无法打开 | 系统设置允许相机权限，或使用粘贴配对 |
| 有历史但不能发消息 | 查看工具能力表，启动原工具并确认兼容桥可用 |

## 网页版：注册、验证码登录与扫码配对

更新：2026-11-01，网页版本 2026.11.01.4。

1. [打开网页版](https://app.leftseinem.com/connect/)，用自己的邮箱验证注册。已有账号可选择邮箱验证码登录或密码登录。
2. 电脑打开 Mydex → 配对手机 → 网页版，生成二维码。
3. 手机网页点击“扫描电脑配对码”，也可从相册读取；核对确认码后绑定。
4. 电脑在线后打开会话。相同账号换设备保留绑定，历史对话从自己的在线电脑加载，不同账号隔离。

验证码十分钟内有效且仅用一次。浏览器完整链路及账号隔离测试通过；手机物理摄像头仍待真机复测。详见[网页教程](https://app.leftseinem.com/apple-guide.html)。

## 删除电脑

手机设置 → 管理已添加电脑 → 删除。离线电脑也可删除，不会删除电脑上的原会话。
