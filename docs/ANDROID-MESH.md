# 当前连接方式（Android 0.2.14 / Windows 0.4.14）

新版无需 Tailscale 账号。更新手机与电脑版后重新扫码一次，优先局域网与当前地址直连，不通时使用加密备用通道。小主机离线时同一局域网可直连，跨网络不保证可用。

<small>使用 VPN 时建议选择规则／分流模式；若无法连接，请关闭全局／TUN 模式后重试。</small>

以下是旧版历史说明，不适用于新版。

# 安卓内置跨网络连接 · 0.2.11

Mydex APK 内嵌 Tailscale tsnet。手机只装 Mydex，每台电脑分别连接；关闭小主机不影响手机连接仍在线的笔记本。关机的那台电脑自身仍无法收发对话。

## 首次连接

1. 电脑安装并登录 Tailscale，保持 Mydex 连接器运行。
2. 手机更新到 0.2.11，在「连接与设置」打开「内置跨网络连接」，点击「登录 Tailscale」，在浏览器登录与电脑相同的账号。返回 Mydex 等待「组网已连接」。
3. 电脑版使用「配对手机 → 应用版 → 生成配对二维码」生成二维码，手机扫码。若电脑版本尚无此按钮，在原连接设置中把地址主机部分改为电脑的 Tailscale IP，例如 `https://100.x.x.x:18443`，保留原访问令牌和证书指纹，再保存。
4. 其他电脑分别添加。每台电脑需要同一 tailnet 中的可访问地址；不会借道另一台用户电脑。

二维码两分钟有效。如果登录时间较长，请先完成登录，再刷新电脑二维码。

## 网络与隐私边界

- 这是应用内网络，不建立系统 VPN，不代理手机其他应用，不需要 GMS。
- Tailscale 负责设备注册、协调和必要时的 DERP 中继；不能承诺所有网络都能直连，也不等于完全没有第三方网络服务。
- 原有 HTTPS 证书指纹及 Bearer 鉴权保留。中继传输加密内容，不存放模型密钥。
- tsnet 诊断日志上传已关闭。设备身份保存于 Android 应用私有 no-backup 目录，卸载清除；不写入公共下载目录。
- 应用在后台可能被安卓省电机制停止；重新打开后重建连接。电脑休眠、离线、账号失效或 tailnet ACL 禁止访问仍会导致不可达。
- 更新从当前已连接的电脑下载；无须指定小主机为中心。

## 构建

使用 Go 1.27.3、Android NDK 28.2.13676358、JDK 21，先运行 `tools/build-mesh.ps1` 生成 `android/app/libs/mydex-mesh.aar`，再运行 `flutter pub get` 和 `flutter build apk --release`。Go 模块及 gomobile 版本已固定；AAR 是本地构建产物，不提交源码仓库。

生成许可清单：在 `native/mesh` 执行 `go list -m -f '{{.Dir}}|{{.Path}}|{{.Version}}' all` 保存输出，然后运行 `tools/collect-mesh-licenses.py <模块列表> <Go目录>`。

发布前构建和签名校验不能替代华为真机测试。首次登录、蜂窝网络连接笔记本、Wi-Fi/流量切换后的恢复、后台恢复，仍需在真实手机上验证。
