# Apple 使用与更新

版本：Mac 0.5.2-preview.2 · 2026-11-03

[官网下载](https://app.leftseinem.dpdns.org/macos.html) · [网页版](https://app.leftseinem.dpdns.org/connect/)

## Mac 安装后自动连接 DeepSeek

选择 Apple Silicon 或 Intel 安装包，退出旧 Mydex 后，将新 Mydex.app 替换到原安装位置，再打开。不要删除 Library/Application Support/Mydex 或原 coding 工具的数据目录，已有账号、配对和原会话数据保留。

这次把已调通的 DSH 桥方案整合进引擎：自动发现当前用户运行的 DeepSeek Harness、本机监听端口和有效的本地签名 Cookie，并验证原会话接口；凭据只在本机使用，连接文件权限600。无需另装Python或LaunchAgent，不读取或上传模型API Key，不改写DSH程序及会话。原有外置桥有效时优先复用；只清理自身管理的失效连接信息，不删除其他工具配置。DSH退出或端口变化后会自动重新发现。

首次仍需在原DeepSeek中完成自己的账号/API配置。Mydex不会代替第三方工具登录，也不会安装内置大模型。工具页分别展示历史读取、原会话续聊、新建能力，不把“找到进程”当成已接通。

## iPhone / 纯血鸿蒙

1. 浏览器打开网页版，使用自己的邮箱账号注册或登录。
2. Mac Mydex选择“配对手机 → 网页中继”，生成网页二维码。
3. 在手机Mydex网页内打开扫码功能并扫描，核对确认码。Android应用二维码不用于网页。
4. iPhone可通过Safari分享菜单“添加到主屏幕”；之后从桌面图标打开。

网页版自动检查同源版本文件，启动、回到前台及约每5分钟检查。发现新版会显示更新提示；发送、审批和草稿处理完成后点击更新。不会自动刷新打断会话，也不会清除账号存储。此次第一次启用自动检查需要刷新当前网页一次；以后不需要下载IPA或重新签名。未安装Google服务的安卓仍继续使用原APK方案。

## Mac 一键更新与重启

从 0.5.2-preview.2 起，设置里的“更新并重启”会完成：下载对应芯片的安装包 → 校验发布签名和完整哈希 → 准备独立安装助手 → 正常退出 Mydex → 备份并替换原应用 → 重新打开并检查启动确认。账号、配对、TLS证书和 Coding 工具会话所在的数据目录不会被删除或重置，也不会退出 DeepSeek 等原工具。

**首次升级例外**：0.5.2-preview.1 及更早的更新器尚无自动替换能力，需要最后一次手动覆盖安装到 0.5.2-preview.2。之后有新版时直接点击更新，不用每次拖应用。

原安装位置需要管理员权限时，由 macOS 显示授权弹窗；取消授权会保留当前应用。安装校验或启动失败时尝试恢复旧程序并重新打开。设置中保留上次更新结果和回退提示；旧程序备份保留供恢复。如果新版进程已启动但没有完成确认，不会强制终止它或在其运行时替换回旧版，而会保留备份和诊断。

请从 Applications 或其他正常安装目录运行，不要从 DMG 或系统临时转置目录直接更新。若检测到旧配置位于应用包内部，更新会停止，避免覆盖数据。更新会短暂断开手机连接，点击前请先完成消息发送和审批。

包仍是 ad-hoc 签名预览版，未 Apple 公证。系统安全确认仍可能需要用户操作；安装助手不会关闭 Gatekeeper 或删除 quarantine 属性。真实管理员弹窗、交互式 GUI 重启尚未在用户 Mac 验证；两种芯片均通过原生文件替换/回退、配置保留、签名与启动确认测试，启动调用由测试回调验证。本轮没有访问用户 Mac。

## Windows 功能对齐与准确范围

| 能力 | Mac / iPhone 当前范围 |
|---|---|
| 多电脑、账号隔离、配对和会话查看 | 共用网页与网关实现；本轮打包引擎协议测试通过，未做真实iPhone扫码 |
| DeepSeek原会话 | 内置自动连接维护；附件报告原机11条历史、send接口可用；本轮未向私人会话发测试消息 |
| DeepSeek新建、权限审批 | 新建能力仍false；权限审批在原桌面完成，与当前Windows同一适配器限制一致 |
| Codex原会话 | 需已安装、登录并运行原桌面；单独CLI或历史目录不能替代；没有的工具不会伪造会话 |
| 模型、快速、队列、目标、侧聊等手机功能 | 共享手机/网页界面与网关实现，具体可用性依赖原工具接口；未逐项完成Mac原机验证 |
| Claude、ZCode等Windows兼容安装/恢复 | Windows专用补丁不会直接套到Mac；尚未提供并验证Mac等效兼容安装，不能称全面对齐完成 |
| OpenClaw | 当前仍为历史读取，原桌面续聊未接通 |
| 菜单栏、登录自启、配对复制、更新 | Mac界面及一键更新已提供；登录项、管理员和辅助功能等授权由用户在系统界面确认 |

双架构CI均通过网关测试、Swift构建、应用签名结构校验与打包引擎配置/配对/TLS/启停测试；这是构建与协议验证，不是用户Mac和真实手机实测。按用户要求，本轮没有访问对方Mac。网页更新通过自动发现、取消保留草稿、确认刷新保留账号存储的浏览器测试。Windows各工具与Mac全部能力完全一致的目标仍有上述差距，未完成部分不会改成“已支持”。
