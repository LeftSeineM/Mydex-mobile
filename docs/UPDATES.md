# 更新与版本

当前版本：Android 0.2.7（10） / Windows 0.4.5。

[下载最新版本](https://github.com/LeftSeineM/Mydex-mobile/releases/latest) · [首页](../README.md)

## 手机更新

设置 → 检查更新 → 下载 → 系统确认安装。APK 使用原签名，可覆盖旧版，无需先卸载。若提示允许安装未知来源，请仅对正在使用的更新入口开启所需安装权限。

更新清单与安装包来自当前连接电脑的更新入口；普通安装者不会自动接入开发者的小主机。电脑端未配置更新源时，可以从公开 Releases 手动下载安装包。

## 电脑更新

退出 Mydex 连接器后运行新版 Setup，保持原安装和数据目录。便携用户先保留 data，再覆盖程序文件。不要清除已有配对配置，也不必重装原 Coding 工具。更新兼容桥需匹配第三方工具版本。

## Android 0.2.6

修复手机将打开已有会话误判为新建会话，导致非 Codex 工具输入框被禁用的问题。原会话需仍由电脑工具提供可写接口；历史文件记录仍只读。设置新增字体缩放 85%–140%，保存后应用并叠加系统字体。

灰色预测输入（Tab 接受建议）仍在接入调查中，本版未包含。电脑端继续使用 0.4.4。

## 0.2.5 / 0.4.4

新增本地相机扫码配对、HTTPS 一次性邀请、两分钟过期与刷新失效；保留粘贴配对。电脑增加二维码窗口与倒计时。公开资料与源码仓库分离，补充完整图文教程和截图。

扫码解码使用随 APK 提供的 ZXing，无需 Google Play 或在线扫码服务。新增相机权限仅用于扫码；拒绝后可以粘贴配对。
